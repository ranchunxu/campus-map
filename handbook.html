板块一 · 游戏底层——学分

1. 学分 = 游戏币 🪙

每门课值几个学分 = 它多"值钱"（学校定死，跟你考多少分无关）。毕业 = 攒够专业要求的总学分。

上理硬性进度线（学籍办法第37条）——数的是"已取得"的学分，挂科多了就可能踩线：

时间节点已取得学分须超过
大一结束25 学分
大二结束60 学分
大三结束100 学分
不达标次数后果
第 1 次学业警示——一年内所有评奖评优取消
第 2 次退学警告 + 降级修读
第 3 次退学

选课弹性：每学期学分可在培养计划建议学分的 ±30% 浮动。

💡 提示卡｜学分

🎯 能干什么：唯一硬通货——攒不够不能毕业；不够进度线触发学业警示/退学。毕业总学分以你专业培养计划为准（✅ v7 已核 2026 官方：上册电信类专业 160 / 医学信息工程 156）。

🎁 怎么拿到：四环链条缺一不可——①教务系统选课成功（蹭课无效）→ ②上满学期别被取消考试资格（旷课/缺作业太多）→ ③参加考核（缺考=0分）→ ④考核及格 ≥60。

📈 怎么提高：学分没有"提高"只有"保住"——每学期选的每门课目标只有一个：及格。挂一门 = 钱花了时间花了进度条不动；及格过的课学分只算一次，重修刷分没意义。

2. 挂科补救流程（背熟，最好用不上）

情形规则补救窗口
期末不及格学分拿不到，绩点记 0补考：下学期初，过了也只记 60 分
补考还不合格仍无学分重修：跟下一届重新上课再考
实践类课程挂科（实验/实习/设计）没有补考只能重修
考前生病等特殊情况可申请缓考下学期再考；缓考没有补考

补考重修成绩如实进档案（绩点真受伤），但评奖学金时不计入。

3. 考试红线 ⚠️⚠️

作弊 = 该科零分 + 纪律处分。连锁反应：处分期间分流排最后、评奖评优全取消；学术失信受留校察看或两次记过，学位证都可能不发（综测同步扣 10~40 分）。手机带进座位响铃都算违纪。别碰。

板块二 · 成绩的两张脸——绩点系 vs 加分系

4. 三层套娃：分数 → 绩点 → GPA 🪆

分数（0~100）：你考出来的原始分，一门课一个。
绩点（0~4.5）：学校把分数按段位换算，一门课一个绩点。
GPA（=平均绩点）：所有课绩点按学分加权平均的总段位。GPA 的 A 就是 Average——名字里写着"平均"。"总绩点"是口语模糊词；官方只有学期平均绩点（这学期）和累计平均绩点（四年总账）。

上理官方换算表（学籍办法第18条），背下来：

💡 提示卡｜绩点 / GPA

🎯 能干什么：累计平均绩点 ≥1.80 才发学位证；转专业、修辅修的基本依据；保研看排名也离不开它。

🎁 怎么得到：不用"得到"，每学期考完自动生成学期 GPA；四年累计就是累计 GPA。

📈 怎么提高：①大课优先——高数 6 学分一门顶六门；②卡档位——78 和 79 都是 2.5，79→80 跳 3.0，复习冲档位线；③别压及格线——60 分绩点只有 1.0，大一大二正是攒 GPA 黄金期。

5. GPA 怎么算（四步）

GPA = Σ（每门课绩点 × 学分）÷ Σ（总学分）

课程学分分数查表→绩点绩点 × 学分
高等数学6924.024.0
大学英语3843.09.0
大学物理4782.510.0
体育1904.04.0
合计14——47.0

GPA = 47.0 ÷ 14 = 3.36。"乘学分"是灵魂：学分就是话语权——体育满分轻轻推一把，高数翻车直接拽下水。

左边按学籍办法第二十条换绩点再平均（GPA，学位线看它）；右边原始分直接平均（加权成绩，分流 90% 看它）。填同一组分，差距一眼看穿。

6. 学分加权成绩 = 分流的真主角 🎯

学分加权成绩 = Σ（每门课原始分数 × 学分）÷ Σ（总学分）——公式和 GPA 一模一样，但乘的是原始分，不换绩点。

同一组成绩（92/84/78/90，学分 6/3/4/1），两种算法各算一遍：

算法乘的是什么计算过程结果
学分加权成绩原始分数（92×6 + 84×3 + 78×4 + 90×1）÷ 1486.1 分（百分制）
GPA换算后的绩点47.0 ÷ 143.36（4.5 制）

一根藤上两个瓜：信息同源，但主战场不同（见下表）。

关键区别：GPA 有档位保护（85 和 89 都是 3.5），加权成绩一分是一分。分流排名零点几分定生死，这条赛道上没有"白考的分"。

💡 提示卡｜学分加权成绩

🎯 能干什么：①大类分流综合成绩的 90%（你进哪个专业的最大变量）；②奖学金分档硬线：三等≥75 / 二等≥80 / 一等≥85 / 特等≥90。

🎁 怎么得到：每学期考完教务系统可见（评奖学金按学期算，重修成绩不计入）。

📈 怎么提高：①学分大的课往死里抓（高数多考 2 分 ≈ 加权 +0.86）；②卡档位策略在这里失效——一分是一分；③每学期修满建议学分（低于 80% 取消奖学金资格）。

板块三 · 课外表现——综测账本 📒

8. 综测一句话结构

综测 = 核心模块（0~60，必须≥50）+ 额外表现（发展+卓越+征兵，合计 0~50）− 违纪扣分，总账封顶 100。

你的综测账本
├─ 口袋A 核心（0~60，必须≥50，B补不上）：晚自习20+各项规定动作40
├─ 口袋B 额外（合计≤50）
│   ├─ B1 发展：学院活动（院外活动一学期最多认2分）
│   ├─ B2 卓越：竞赛/论文/专利/荣誉/学生工作
│   └─ B3 征兵：报名体检+3 / 正式入伍+40
└─ 口袋C 扣分：警告-10 / 严重警告-20 / 记过-30 / 留校察看-40

💡 提示卡｜综测

🎯 能干什么：①大类分流综合成绩的 10%；②奖学金评定的德育资格线（不达标，加权再高也取消资格）；③评优依据。它是防守型分数：守住白送分，守不住会咬人（晚自习翘一学期 = 综合成绩白丢 2 分）。

🎁 怎么得到：核心模块靠考勤自动到账；发展模块参加学院活动（老师报名单）；卓越模块自己交材料申请（限参评学年内、上理本科生身份，同一成果只用一次）；违纪自动扣。

📈 怎么提高：①晚自习全勤（全表最大单项 20 分）；②规定动作一个不漏；③开学竞选班委；④偶尔凑学院活动；⑤大二再上竞赛/专利。⚠️ 大家实际挤在 55~70 分，B 口袋凑到 40 就顶格——拉开差距靠"谁缺勤多"，不靠"谁活动多"。

板块四 · 排名决定什么

10. 综合成绩 = 为分流现做的一次性成绩 🏁

综合成绩 = 学分加权成绩 × 90% + 综测 × 10%——大一末算一次，全大类排名，用完退役（像高考总分）。
但原料不退役：加权成绩每学期继续发奖学金，综测每学期继续卡评奖资格。

12. 转专业 = 另一扇门

分流之外换专业的渠道：条件各学院自定并公示，转入学院组织考核。【通用】窗口一般在大一学年末。分流不理想时的补救渠道。

13. 毕业证 ≠ 学位证 📜

累计平均绩点 ≥ 1.80 才有学士学位 ≈ 四年平均每门课稳在 64 分档以上。摆烂四年真有人够不着——毕业证拿了学位证没拿，考研考公很多岗直接卡死。

17. 社团

校团委注册+年审制。1 个兴趣 + 1 个技能/学术，别贪多。混成骨干 = 综测加分 + 评奖材料。

18. 学生工作

班委大一最容易选上，性价比最高（综测 + 社会工作奖 200 元 + 评优材料）。⚠️ 服务岗不是权力岗，别耽误学习。
