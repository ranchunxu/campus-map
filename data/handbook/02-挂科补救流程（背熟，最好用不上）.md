# 2. 挂科补救流程（背熟，最好用不上）

| 情形 | 规则 | 补救窗口 |
| --- | --- | --- |
| 期末不及格 | 学分拿不到，绩点记 0 | **补考**：下学期初，过了也只记 60 分 |
| 补考还不合格 | 仍无学分 | **重修**：跟下一届重新上课再考 |
| 实践类课程挂科（实验/实习/设计） | **没有补考** | 只能重修 |
| 考前生病等特殊情况 | 可申请**缓考** | 下学期再考；缓考没有补考 |
| 毕业那学期挂科 | **没有补考资格** | 直接威胁毕业，务必提前避坑 |

补考重修成绩如实进档案（绩点真受伤），但评奖学金时不计入。
