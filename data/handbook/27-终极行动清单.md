# ✅ 终极行动清单

| 时间点 | 做什么 |
| --- | --- |
| **开学一周内** | 改掉所有初始密码；找辅导员要①学院综测细则（←基础学院版已到手）②培养计划电子版 |
| **报到前后** | 英语分级测试尽力考高——决定英语课起点，也是格致创新班的门槛 |
| **第一学期** | 一切为加权成绩让路（高数最大权重）；晚自习全勤；班委或社团选一个 |
| **11 月前后** | 想入党就交申请书（早交早排队） |
| **寒假** | 完成寒假大作业（综测 6 分）+ 摸清 13 个分流专业出路 |
| **大一下填志愿前** | 找直系学长要**往年各专业实际分流位次线**——比任何官方文件都真实 |
| **每学期 14~16 周** | 综测公示期核对分数，漏记当场找辅导员 |
