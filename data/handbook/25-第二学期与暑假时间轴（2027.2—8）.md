# 25. 第二学期与暑假时间轴（2027.2—8）

| 时间 | 事项 | 备注 |
| --- | --- | --- |
| 1月底—2月初 | 美赛 | 寒假约4天，可体验；**⚠️ 不在校定A类名单内**，综测/评奖认定口径先问学院 |
| 2月底—3月初 | 新学期开学 |   |
| 3月 | 计算机等级考试 NCRE | 每年3/9月两次 |
| 3月 | 中国国际大学生创新大赛报名 **校定A类 #1** | 3-5月报名，建议跟学长组队 |
| 3月初 | 英语竞赛 NECCS 报名截止 | 12月起报 |
| 3—5月 | **大创申报** | 校级项目大一可牵头 |
| 4月 | NECCS 初赛 / 蓝桥杯省赛 | 校定A类 #79 / #27 |
| 5月 | NECCS 决赛 | 初赛晋级者 |
| **5月底—6月** | **大类分流志愿填报** | 13个专业按综合成绩+志愿分流（v7：2026 级起候选名单已更新） |
| 6月中上旬 | 蓝桥杯总决赛 | 省赛一等奖晋级 |
| 6月中旬（预计） | 四六级笔试 | 待官方公布 |
| **6月底—7月** | **分流结果公布** | 期末成绩录入后定专业，公示转学籍 |
| 6月底—7月 | 期末考试周 | 大一全年绩点定分流去留 |
| 7月上旬 | 暑假开始 | 可社会实践/三下乡 |
| 8月 | 全国大学生电子设计竞赛 **校定A类 #6** | 奇数年举办，可参加校内选拔 |
