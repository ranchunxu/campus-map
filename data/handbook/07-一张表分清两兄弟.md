# 7. 一张表分清两兄弟

|   | GPA | 学分加权成绩 |
| --- | --- | --- |
| 乘的是什么 | 换算后的绩点（0~4.5） | 原始分数（0~100） |
| 满分 | 4.5 | 100 |
| 档位保护 | 有（5分一档） | **无，一分是一分** |
| 主战场 | 学位证、转专业、保研 | **分流 90%、奖学金分档** |
| 策略 | 冲档位线 | 每一分都咬 |
