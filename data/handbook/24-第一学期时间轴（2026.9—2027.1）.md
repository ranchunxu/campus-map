# 24. 第一学期时间轴（2026.9—2027.1）

*合并自你的《大一时间表》xlsx · 报到日期为录取通知书确认信息 · **用法：每月初翻一遍，报名窗口设手机提醒***

| 时间 | 事项 | 备注 |
| --- | --- | --- |
| **9月19日（周六）** | **新生开学报到** | 你的开学日；2026.9 无军训（✅ v7 官方定档：军训排大一短1） |
| 9月中下旬 | 入学教育、选课、体检、社团招新 | 无军训时间宽裕，尽早熟悉校园 |
| 9月中下旬 | **四六级报名（下半年）** | 窗口仅7-10天，错过无补报，能报四级就报 |
| 9月中旬 | 数学建模国赛 **校定A类 #5** | 已过报名期，可观摩积累 |
| 10—11月 | 数学竞赛 CMC 初赛 **校定A类 #80** | 大一可报低年级组 |
| 11月21—22日 | 四六级口语考试 | 选考、机考 |
| 11月中下旬 | 期中考试周 | 约第9-10教学周 |
| 10—12月中 | **蓝桥杯报名** **校定A类 #27** | 大一上可报，2027年4月省赛 |
| **12月12日** | **四级/六级笔试** | 四级上午9:00、六级下午15:00 |
| 12月底—1月中 | **期末考试周** | 绩点直接关系分流排名 |
| 1月中下旬 | 寒假开始 | 2027年春节2月6日 |
